# 운동 자세 학습과 검증 기록

## 일반 운동 GOOD/BAD

Mendeley 다중 시점 자료의 영상 1,042개 중 828개를 사용했습니다. 참가자 26개 그룹을 기준으로 학습 497개, 검증 157개, 테스트 174개로 나눴습니다. 여러 사람으로 대상이 불명확한 영상 172개, 라벨 충돌 21개, 관절 품질 미달 13개, 동일 해시 중복 8개를 제외했습니다. [Mendeley 원자료](https://data.mendeley.com/datasets/kgbb3yn47p/3)

아래 수치는 운동 종류가 주어진 상태에서 영상 단위 자세 분류를 평가한 결과입니다. 운동 인식과 자세 인식을 연결한 별도 테스트에서는 실제 앱의 보류 임계값 적용 전 공동 정확도가 174개에서 53.4%였습니다. [집계 지표](../results/mendeley_v4.json)

테스트 174개 전체는 운동 인식 기준입니다. 운동별 자세 분류는 해당 모델의 평가 가능 영상만 집계했습니다. 플랭크의 엉덩이 높낮이와 바이셉 컬의 상체 뒤로 젖힘은 별도 프레임 오류 라벨로 시험했으며, 해당 프레임 자료에는 사람 단위 독립 평가 근거가 충분하지 않습니다. 같은 Mendeley 원자료를 사용한 별도 확장 실험에서는 운동 인식 23개와 자세 분류 7개를 확인했습니다.

### Mendeley v4 실행하기

Python 환경에 기록된 의존성을 설치하고, Mendeley v3 영상의 폴더와 이름을 유지한 채 `inputs/mendeley-v3`에 준비합니다. 예시 설정은 일반 운동 영상 학습을 실행하며, 별도 플랭크·바이셉 컬 프레임 CSV 사용은 꺼져 있습니다. 최초 실행 시 MediaPipe 관절 추출 모델을 내려받고 환경 검사를 진행합니다. [학습·추론 코드](../scripts/fitness_runtime_v4.py) · [예시 설정](../config/mendeley-v4.example.json)

```bash
python -m pip install -r config/requirements-v4.txt
python scripts/fitness_runtime_v4.py --config config/mendeley-v4.example.json
python scripts/fitness_runtime_v4.py --bundle runs/mendeley-v4 --predict sample.mp4 --exercise squat
```

학습한 실행 폴더에는 모델과 자세 분류 평가, 참가자 단위 분할표, 제외 이유가 남습니다. 이전 출력을 보존하려면 새 실행마다 `OUT`과 `WORK`를 새 경로로 지정합니다.

## 데드리프트와 37개 세부 동작

데드리프트는 기존 자세 분류에 종목을 추가하는 방식으로 별도 버전을 만들었습니다. 보존된 V6 모델의 외부 영상 한 편에서 입력부터 결과 출력까지 동작을 확인했습니다. 정답이 있는 외부 테스트를 별도로 실시해야 자세 성능을 알 수 있습니다.

37개 동작 프로토타입에서 펙덱 플라이, 풀업, 레그 익스텐션, 트라이셉 푸시다운, 딥스, 벤치프레스, 인클라인 벤치프레스는 정상 참조 모델에 연결됐습니다. 데드리프트만 이진 분류에 연결됐고, 29개 동작은 자료·모델 확보가 남았습니다. [당시 프로토타입 전체 목록](../results/prototype_37.csv)

## 기구용 피드백에 앞서 확인한 사항

- 트레드밀 보행 1명 자료에서 관절각 측정값을 비교했고, 자전거·일립티컬 영상에서는 프레임별 인물 검출을 점검했습니다. 자세의 정상·오류 라벨을 예측하는 평가에 앞선 측정입니다.
- 시티드 로우, 레그 익스텐션·컬, 체스트 프레스·숄더 프레스, 레그 프레스, 케이블 크로스오버에서는 관절·기구 움직임의 관측 가능성과 동작 후보를 조사했습니다. 대략적인 반복 수 후보를 얻은 표본도 있었지만, 현장 영상과 오류 라벨이 필요합니다.
- 현장 시험은 장비와 운동 변형을 먼저 고정하고 촬영 참가자를 분리한 뒤, 기준별 오탐·미탐과 카메라 입력 조건을 기록하는 단계가 남아 있습니다. [26개 기구별 현재 상태](../TRAINING_DATA.md)
